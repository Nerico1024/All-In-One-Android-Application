# All-In-One Blue Collar Jobs

An Android-based job search and recruitment application developed as part of a Bachelor of Science in Information Technology academic thesis project.

## Project Overview

All-In-One is a mobile recruitment platform designed to connect skilled, unskilled, and informal-sector workers with potential employers.

The application aims to improve employment accessibility by providing a centralized platform for job searching, job posting, and job applications.

Developed using Java in Android Studio, with Firebase serving as the backend and database platform.

## Features

- **User Registration & Login** – User account registration and authentication.
- **Job Searching** – Browse and discover available job opportunities.
- **Job Posting** – Allow employers to publish employment opportunities.
- **Job Application** – Enable job seekers to apply for available positions.
